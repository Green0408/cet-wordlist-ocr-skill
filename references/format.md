# OCR 词表导入格式说明

给 agent / 外部 OCR 工具用的规范：先把扫描版 PDF 识别成 **软件可直接导入的纯文本**，再导入《四六级背单词》。

适用场景：

- PDF 没有文字层，应用内 OCR 不稳定
- 双栏词表、带音标、页眉页脚、表格线
- 想让 agent 在线逐页识别，人工只做少量校对

---

## 一、最终产物

一个 **UTF-8 编码的 `.txt` 文件**，不要 Markdown 表格，不要 CSV，不要代码围栏。

文件名建议：

```text
四级高频词汇-OCR.txt
```

---

## 二、格式总则

### 1. 每页以固定分隔线开头

```text
===== 第 1 页 =====
```

要求：

- `=` 至少 3 个
- 「第」「页」之间可以有空格
- 页码用 PDF 的真实页码
- 不要把分隔线写成 Markdown 标题，例如 `# 第 1 页` 不行

### 2. 一个词一行

每行格式：

```text
英文单词 + [音标]（可选）+ 词性（可选）+ 中文释义
```

示例：

```text
expand [ɪkˈspænd] v. (使)膨胀；扩大
sufficient [səˈfɪʃənt] a. 足够的；充分的
rotate [rəʊˈteɪt] v. (使)旋转
```

也允许不带词性：

```text
expand (使)膨胀；扩大
```

### 3. 一行只能有一个词

错误：

```text
expand v. (使)膨胀    vary v. 改变
```

正确：

```text
expand v. (使)膨胀
vary v. 改变
```

### 4. 音标写在方括号里

推荐：

```text
expand [ɪkˈspænd] v. (使)膨胀
```

也接受：

```text
expand 【ɪkˈspænd】 v. (使)膨胀
```

规则：

- 音标放在英文单词后、词性/释义前
- 用方括号包住，左右括号必须成对
- 保留重音符号和 IPA 字符，不要改写成拼音
- 页面上没有音标或看不清时直接省略，不要编造
- 斜杠 `/.../` 不作为标准格式输出，统一改成方括号

### 5. 释义必须是中文

软件靠「英文词头后面的第一段中文」切分单词和释义。

只有英文、没有中文的行会被丢弃：

```text
expand
```

### 6. 释义续行合并到上一条

OCR 经常把一条释义拆成两行：

```text
expand v. (使)膨胀
扩大；扩张
```

要合并成：

```text
expand v. (使)膨胀；扩大；扩张
```

不要保留只有中文的独立行。

### 7. 双栏按「左栏读完，再读右栏」

不要按视觉同一行左右拼接。

错误：

```text
expand v. (使)膨胀    vary v. 改变
```

正确：

```text
expand v. (使)膨胀
sufficient a. 足够的
rotate v. 旋转
vary v. 改变
resent v. 愤恨
revolve v. 旋转
```

### 8. 删除页眉、页脚、书名、日期、水印

这些不要进入词表：

```text
大学英语四级词汇
DAY 1
第 1 页 共 31 页
```

页码只保留在 `===== 第 N 页 =====` 分隔线里。

### 9. 去掉题号、项目符号、表格线

不要输出：

```text
1. expand v. ...
• expand v. ...
| expand | v. | ... |
```

要输出：

```text
expand v. ...
```

### 10. 去重

同一个单词只保留第一次出现，大小写不敏感。

---

## 三、完整示例

```text
===== 第 1 页 =====
expand [ɪkˈspænd] v. (使)膨胀；扩大
sufficient [səˈfɪʃənt] a. 足够的；充分的
rotate [rəʊˈteɪt] v. (使)旋转
vary [ˈveəri] v. 改变；变化
resent [rɪˈzent] v. 愤恨；怨恨
revolve [rɪˈvɒlv] v. (使)旋转

===== 第 2 页 =====
abandon [əˈbændən] v. 放弃；抛弃
absorb [əbˈsɔːb] v. 吸收；使专心
abstract [ˈæbstrækt] a. 抽象的
```

注意：

- 页与页之间空一行可以，空行会被忽略
- 每页内不要按左右栏交错
- 每条释义尽量控制在 140 个字符以内

## 四、给 agent 的 OCR 指令模板

可以把下面整段连同 PDF 一起交给带视觉能力的 agent：

```text
你是词表 OCR 校对员。请逐页识别附件 PDF，输出《四六级背单词》可直接导入的纯文本。

硬性要求：
1. 只在第一行输出页码分隔线，格式必须是：
   ===== 第 N 页 =====
2. 一个词一行，格式为：
   英文单词 + [音标]（可选）+ 词性（可选）+ 中文释义
3. 一行只能有一个单词。双栏页面先读完左栏，再读右栏，绝不把左右栏拼在同一行。
4. 音标保留在方括号里，例如 [ɪkˈspænd] 或 【ɪkˈspænd】；看不清就不写，不要编造。
5. 删除页眉、页脚、书名、DAY/Unit/List 标题、题号、表格线、水印。
6. 释义换行时合并到上一条，不要留下只有中文的行。
7. 不要翻译、改写、补写释义；只保留页面上真实存在的中文。
8. 同一单词只输出一次。
9. 只输出纯文本，不要 Markdown 表格、不要代码围栏、不要解释。
10. 不要安装任何依赖：禁止 pip / npm / winget / apt / brew，禁止下载模型。
    不能直接读 PDF 就停下来要页面图片，不要尝试装渲染库。

输出示例：
===== 第 1 页 =====
expand [ɪkˈspænd] v. (使)膨胀；扩大
sufficient [səˈfɪʃənt] a. 足够的；充分的
rotate [rəʊˈteɪt] v. (使)旋转
```

如果 agent 支持写入文件，让它直接保存为 **UTF-8 的 `.txt`**；如果只在对话里输出，复制到本地 `.txt` 即可。

## 五、导入软件

1. 打开《四六级背单词》
2. 进入「导入」页
3. 选择 **TXT / MD** 中的 `.txt`
4. 确认预览区出现：
   - `解析到 N 词`
   - `N 页`
5. 在「校对词条」里检查前几条和最后几条
6. 填写词书名称、每周页数 / 词数
7. 创建词书

导入成功后，PDF 的页码会保留，可以继续按页制定每周计划。

---

## 六、自检清单

给 agent 或人工校对用：

- [ ] 文件是 UTF-8，扩展名 `.txt`
- [ ] 每页第一行是 `===== 第 N 页 =====`
- [ ] 音标放在方括号内、左右括号成对
- [ ] 没有把音标拼进英文词头，也没有编造音标
- [ ] 没有一行两个单词
- [ ] 没有只有英文、没有中文释义的行
- [ ] 没有只有中文、没有英文词头的独立行
- [ ] 没有页眉、页脚、DAY、Unit、List、书名
- [ ] 没有 Markdown 表格和项目符号
- [ ] 同名单词只出现一次
- [ ] 预览区词数、页数与 PDF 大致相符

---

## 七、常见问题

### 预览显示 0 词

检查：

- 每行是否以英文字母开头
- 单词后面是否有中文释义
- 页码分隔线是否写成了 Markdown 标题
- 音标是否放在单词后，且左右方括号完整

### 某个词的释义串到了下一个词

典型原因是双栏被拼成一行。回到 OCR 步骤，按「左栏读完再读右栏」重新输出。

### 词数比 PDF 少很多

检查：

- 是否把只有中文的续行当成了独立行
- 是否因为单词重复被去重
- 是否有大量行只有英文没有中文

### 页码不对

页码只影响按页制定计划，不影响词条本身。可以统一改成 `===== 第 1 页 =====`，但按页计划会失效。
